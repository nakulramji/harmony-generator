Model splitter

GitHub's website only accepts files up to 25 MB, and the AI model is bigger. This page cuts it into 20 MB pieces and writes the manifest.json file the website needs. Nothing is uploaded: it all happens on your computer.

1. Choose the model file (for example Kim_Vocal_2.onnx):

2. Click the button. Your browser saves several files (it may ask to allow multiple downloads: say yes).

    3. Upload all of these files into the models folder of your GitHub repository.
